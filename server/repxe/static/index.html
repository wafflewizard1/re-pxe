Restore database
This replaces the current database with the selected snapshot. Records and settings created since that snapshot will no longer be current. All website sessions will sign out. Restored pending jobs are cancelled and their credentials revoked; they will not resume on a PC.
Restore is blocked while machine jobs or sessions are active. A verified snapshot of the current database is preserved first. Published image, driver, boot and text files are not replaced.
