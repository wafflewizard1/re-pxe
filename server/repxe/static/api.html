Authentication and upload flow

Send an Authorization header with Bearer <role token>. Capture uploads images; agents upload drivers and completion reports; deployment clients create jobs and send WinPE stage events; administrators review and publish artifacts.

Create an upload → PATCH raw bytes in chunks of at most 16 MiB with an Upload-Offset header → finish validation → administrator publication. Query the upload ID to recover the durable offset after a disconnect. Driver publication requires a successful hardware test declaration.

The server records client-reported job stages. It does not perform imaging or certify a physical device's success.
